# Algorithms
 - We evaluate the performance of an algo in terms of input size 
 # Time complexity 
    - Amount of time taken by an algo to run ,as a function of input size
 # Space complexity 
    - Amount of memory taken by an algo to run ,as a function of input size

- Mathematical tool to represent time and space complexity 
- 1. Big-O Notation - Worst case complexity 
- 2. Omega Notation - Best case complexity 
- 3. Theta Notation - Average case complexity
